# **Life OS 初始儲存架構與資料庫設計文件 (v1.0)**

## **系統儲存哲學：混合式本地優先 (Hybrid Local-First)**

本系統嚴格遵循「單向淨化原則」：

1. **\[擷取\]** 最敏感明文（程式碼、網頁內文、私人對話） $\\rightarrow$ 絕對鎖在本地 SQLite。  
2. **\[淨化\]** 邊緣端 AI (iPad M1) 將明文壓縮為意圖標籤 $\\rightarrow$ 暫存於本地 SQLite，定期上雲。  
3. **\[固化\]** 雲端 Gemini 將標籤提煉為薩提爾冰山圖譜 $\\rightarrow$ 永久存入雲端 Neo4j。  
4. **\[業務\]** 跨裝置狀態、多智能體專家配置、遊戲化資產 $\\rightarrow$ 存入雲端 PostgreSQL。

## **第一區：🛡️ 本地隱私金庫 (Local SQLite)**

**定位**：絕對不上雲的私有資料庫。儲存原始追蹤日誌、逐字對話紀錄與邊緣推論中繼資料。

**實作技術**：SQLite 3 (內嵌於 Tauri 應用程式中)

### **1\. raw\_tracking\_logs (原始行為追蹤紀錄)**

* **用途**：紀錄最原始的系統操作、程式碼變更與網頁內文。僅供邊緣端 AI 讀取。  
* **生命週期**：短暫 (建議 3\~7 天滾動刪除)。  
* **Schema**:  
  * id (TEXT, UUID Primary Key)  
  * timestamp (DATETIME) \- 事件發生時間  
  * source (TEXT) \- 來源 (例如：'vscode', 'chrome\_extension', 'word')  
  * raw\_text (TEXT) \- 明文內容 (程式碼、文本)

### **2\. chat\_transcripts (歷史對話逐字稿)**

* **用途**：您與所有 AI 專家 (Persona Agents) 的私密對話紀錄明文。  
* **生命週期**：永久保存於本地，供日後搜尋與上下文接續。  
* **Schema**:  
  * id (TEXT, UUID Primary Key)  
  * thread\_id (TEXT) \- 對話串 ID (對應特定任務或專家)  
  * role (TEXT) \- 角色 ('user' 或 'assistant')  
  * content (TEXT) \- 對話明文  
  * timestamp (DATETIME)

### **3\. edge\_event\_buffer (Edge 推論流水帳)**

* **用途**：接收 iPad M1 推論出來的「去識別化意圖標籤」。作為上雲前的緩衝區。  
* **生命週期**：中繼暫存，批次上傳至雲端 Neo4j 後即可標記刪除/封存。  
* **Schema**:  
  * id (TEXT, UUID Primary Key)  
  * timestamp (DATETIME)  
  * intent\_tag (TEXT) \- 意圖標籤 (例如：'焦慮', '鑽研', '逃避')  
  * is\_synced (BOOLEAN) \- 是否已同步至雲端圖譜 (預設 False)

## **第二區：🧠 雲端潛意識大腦 (Neo4j AuraDB)**

**定位**：長期動態演化的個人知識與心理圖譜。

**實作技術**：Neo4j AuraDB Free (透過 Cypher 語法操作)

### **4\. 薩提爾冰山動態圖譜 (Satir Iceberg Graph)**

* **用途**：儲存透過標籤提煉出的深層心理關聯，作為 AI 專家分析您認知負載與行為慣性的決策大腦。  
* **生命週期**：永久保存，伴隨成長動態改變權重與關聯。  
* **Schema (Nodes 節點)**:  
  * (:Behavior) \- 表層行為 (例：連續除錯3小時)  
  * (:CopingStance) \- 應對姿態 (例：超理智)  
  * (:Feeling) \- 感受 (例：挫折、焦慮)  
  * (:Expectation) \- 期待 (例：期待自己全能)  
  * (:Yearning) \- 渴望 (例：掌控感、被認可)  
* **Schema (Edges 關係)**:  
  * (Behavior)-\[:REFLECTS\]-\>(CopingStance)  
  * (CopingStance)-\[:DRIVEN\_BY\]-\>(Feeling)  
  * (Feeling)-\[:STEMS\_FROM\]-\>(Expectation)  
  * (Expectation)-\[:ROOTED\_IN\]-\>(Yearning)  
  * (Behavior)-\[:NEXT\_EVENT {time\_delta}\]-\>(Behavior) \- 雙時態行為軌跡

## **第三區：☁️ 雲端核心業務與多智能體 (PostgreSQL)**

**定位**：跨裝置無縫同步的應用層資料庫，處理多智能體配置、遊戲化進度與 UI 呈現。

**實作技術**：PostgreSQL (部署於 Render/Supabase 等 PaaS)

### **5\. users (使用者主檔與 RPG 角色)**

* **用途**：全域狀態、帳號資訊與遊戲化等級。  
* **Schema**:  
  * id (UUID Primary Key)  
  * username (VARCHAR)  
  * current\_xp (INTEGER) \- 累積經驗值  
  * level (INTEGER) \- 當前等級  
  * rpg\_class (VARCHAR) \- 職業設定 (例如：'Debug 法師')  
  * avatar\_url (VARCHAR) \- 角色大頭貼網址

### **6\. ai\_experts (專屬配對的專家陣列)**

* **用途**：系統為您生成的專屬教練配置與人設。  
* **Schema**:  
  * id (UUID Primary Key)  
  * user\_id (UUID, Foreign Key)  
  * expert\_name (VARCHAR) \- 專家名稱 (例如：'嚴厲導師 Alan')  
  * personality\_prompt (TEXT) \- 驅動該專家的底層系統提示詞  
  * trust\_level (INTEGER) \- 親密度/信任度 (影響對話語氣)

### **7\. expert\_homepages (專家主頁與 UI 配置)**

* **用途**：專家個人頁面的視覺化配置。  
* **Schema**:  
  * expert\_id (UUID Primary Key, FK to ai\_experts)  
  * background\_image\_url (VARCHAR) \- Leonardo.ai 生成的背景圖  
  * unlocked\_features (JSONB) \- 該專家目前解鎖的互動模式

### **8\. expert\_projects (專家管理的專案/目標)**

* **用途**：交給特定專家監督的任務與里程碑。  
* **Schema**:  
  * id (UUID Primary Key)  
  * expert\_id (UUID, Foreign Key)  
  * title (VARCHAR) \- 專案名稱  
  * status (VARCHAR) \- 狀態 ('active', 'completed', 'paused')  
  * progress\_percentage (INTEGER) \- 完成度 0-100

### **9\. daily\_reports (每日覺察與總結報告)**

* **用途**：深夜基於 Neo4j 圖譜生成的去識別化成長日誌，供跨裝置回顧。  
* **Schema**:  
  * id (UUID Primary Key)  
  * user\_id (UUID, Foreign Key)  
  * report\_date (DATE)  
  * summary\_text (TEXT) \- 綜合評語  
  * mood\_score (INTEGER) \- 情緒指數 (1-10)  
  * key\_insights (JSONB) \- 條列式關鍵覺察

### **10\. zpd\_tasks (ZPD 盲盒任務池)**

* **用途**：預先生成的近側發展區挑戰，支援 0 毫秒跨裝置抽取。  
* **Schema**:  
  * id (UUID Primary Key)  
  * user\_id (UUID, Foreign Key)  
  * task\_text (TEXT) \- 任務內容  
  * difficulty (VARCHAR) \- 難度 ('Easy', 'Medium', 'Hard')  
  * xp\_reward (INTEGER) \- 獎勵點數  
  * asset\_url (VARCHAR) \- Leonardo.ai 生成的卡牌圖示  
  * status (VARCHAR) \- 狀態 ('pending', 'drawn', 'completed')

### **11\. social\_posts (社群互動與公開牆)**

* **用途**：使用者手動核准發布的成就或對賭承諾。  
* **Schema**:  
  * id (UUID Primary Key)  
  * user\_id (UUID, Foreign Key)  
  * content (TEXT) \- 貼文內容或里程碑  
  * likes\_count (INTEGER) \- 按讚/加油數  
  * created\_at (TIMESTAMP)

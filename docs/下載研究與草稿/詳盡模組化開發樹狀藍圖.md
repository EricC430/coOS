# **Life OS 終極模組化開發樹狀藍圖 (v1.0)**

**開發策略**：Top-Down Design, Bottom-Up Implementation。 **模組標籤**：

* `[MVP]`：最小可行性產品必備模組（第一階段實作）。  
* `[進階]`：Beta 版或正式商業化階段擴充模組（第二階段實作）。

  ## **📦 \[M0\] 專案基礎建設與整合 (Monorepo Infrastructure)**

* **\[M0.1\] 環境與工作區配置** `[MVP]`：Node.js/Rust/Python Monorepo 架構、`.env` 統一管理。  
* **\[M0.2\] Tauri Sidecar 行程管理** `[MVP]`：封裝 FastAPI，使其隨 Tauri 主程式啟動/關閉，並確保 Port 衝突處理。  
* **\[M0.3\] 資料庫遷移與初始化腳本** `[MVP]`：SQLite 結構建置腳本、Neo4j 連線健康檢查 (Health Check)。

  ## **👁️ \[M1\] 全域感知與追蹤層 (Ambient Sensing Modules)**

*(負責無感擷取各類軟體的原始操作明文)*

* **\[M1.1\] OS 層級系統監聽器 (Rust Core)**  
  * `[M1.1.1] UIAutomation 輔助 API 橋接` `[MVP]`：讀取 Windows UI 樹狀結構，抓取 Word/Notion 等非網頁軟體的標題與純文字內容。  
  * `[M1.1.2] 全域鍵鼠遙測 (Telemetry)` `[MVP]`：非侵入式計算敲擊頻率 (WPM) 與滑鼠移動熱區，不紀錄密碼。  
  * `[M1.1.3] 系統狀態與電源監控` `[MVP]`：偵測系統休眠、全螢幕模式，作為「是否打斷使用者」的上下文。  
  * `[M1.1.4] 進階 OCR 視覺截取` `[進階]`：針對無法讀取 DOM 的軟體，定時截圖並於本地執行輕量級 OCR (如 Tesseract) 提取關鍵字。  
* **\[M1.2\] IDE 深度追蹤 (VS Code Extension)**  
  * `[M1.2.1] AST (抽象語法樹) 攔截器` `[MVP]`：監控特定函數修改、報錯行停留時間。  
  * `[M1.2.2] IPC 管道傳輸` `[MVP]`：將 VS Code 收集的資料透過 Local Socket 即時傳給 Tauri。  
* **\[M1.3\] Web 深度追蹤 (Chrome/Edge Extension)**  
  * `[M1.3.1] DOM 滾動與反白監聽` `[進階]`：精確記錄使用者在 StackOverflow 或技術文件的停留深度與複製行為。  
  * `[M1.3.2] 擴充套件 IPC 橋接` `[進階]`：透過 Native Messaging 將網頁日誌傳回 Tauri。

    ## **🛡️ \[M2\] 邊緣壓縮與隱私防禦層 (Edge Privacy & Compression)**

*(負責將明文轉化為意圖，並阻斷隱私外洩)*

* **\[M2.1\] 邊緣通訊引擎 (Rust)**  
  * `[M2.1.1] 智慧防抖與打包佇列` `[MVP]`：以 30\~60 秒為時間窗，合併多重感測器事件。  
  * `[M2.1.2] ai.local API 負載平衡` `[MVP]`：透過 Wi-Fi 發送至 iPad，處理斷線重連與逾時。  
* **\[M2.2\] 意圖向量壓縮器 (Intent Vector Pipeline)**  
  * `[M2.2.1] Few-Shot 標籤化 Prompt 引擎` `[MVP]`：設計系統提示詞，引導 Gemma 4 將程式碼行為提煉為結構化 JSON。  
* **\[M2.3\] Eguard 密碼學過濾防禦網 (Eguard Firewall)**  
  * `[M2.3.1] PII (個人識別資訊) 遮蔽器` `[MVP]`：利用 Regex 在本地端強制消除可能殘留的 Email、IP、Token。  
  * `[M2.3.2] 脈絡雜湊驗證 (Context Hashing)` `[進階]`：對原始碼明文進行 SHA-256 雜湊並附加於意圖標籤，雲端驗證時可確認該推論具備實體根據，防止邊緣端遭越獄注入。

    ## **🖥️ \[M3\] 互動介面與呈現層 (React / UI Modules)**

*(打造極致遊戲化與深度沉浸體驗)*

* **\[M3.1\] 核心儀表板 (Main Dashboard)**  
  * `[M3.1.1] 角色狀態視圖 (RPG Avatar)` `[MVP]`：展示目前的 XP、職業 (例: Debug法師)、等級進度條。  
  * `[M3.1.2] 動態背景與粒子特效` `[進階]`：依據當前心理狀態 (如：焦慮時畫面邊緣泛紅，平靜時藍色微光) 切換。  
* **\[M3.2\] 多智能體專家矩陣 (AI Expert Personas)**  
  * `[M3.2.1] 專家主頁與立繪展示` `[MVP]`：顯示不同專家 (嚴厲導師、安撫教練) 的 Leonardo.ai 靜態/動態立繪與信任度。  
  * `[M3.2.2] 專案管理視圖 (Expert Projects)` `[MVP]`：展示交由特定專家追蹤的長期任務進度 (如：畢業論文)。  
* **\[M3.3\] 沉浸式對話介面 (Chat UI)**  
  * `[M3.3.1] 多模態輸入與 Markdown 渲染` `[MVP]`：支援程式碼區塊高亮、語音意識流麥克風輸入、打字機輸出特效。  
  * `[M3.3.2] 脈絡內工作流與資料源綁定面板 (In-Context Hook/Connection)` `[MVP]`：於對話框內無縫喚出設定面板，隨時綁定 GitHub Repo、瀏覽器監聽器，並自訂自動化觸發條件。  
  * `[M3.3.3] 隱形進度與自動主題標記UI (Auto-Project Progress UI)` `[MVP]`：聊天流下方自動浮現「*Project 偵測為『初始目標設定』創立*」提示，並即時渲染非零初始進度條 (賦予進展效應)。  
  * `[M3.3.4] Echo Mode 語氣感知特效` `[進階]`：當切換至「共鳴傾聽」模式時，UI 文字顯現速度變慢，字體邊緣柔化。  
* **\[M3.4\] 數據與成長回顧 (Insights & Reflection)**  
  * `[M3.4.1] 每日覺察報告 (Daily Summary)` `[MVP]`：時間軸呈現今日情緒起伏與關鍵心理洞察。  
  * `[M3.4.2] 薩提爾冰山圖譜視覺化` `[進階]`：使用 D3.js 或 React Flow 將 Neo4j 中的渴望與行為繪製成 3D/2D 節點圖。  
* **\[M3.5\] 收藏櫃與遊戲化經濟 (Collection & Gamification Economy)**  
  * `[M3.5.1] 視覺化成就展示櫃 (Collection Showcase)` `[MVP]`：集中展示已獲得的徽章、專案里程碑與動態隱藏成就解鎖牆。  
  * `[M3.5.2] 探索盲盒抽卡介面 (Exploration Gacha UI)` `[MVP]`：消耗 XP 抽取未知動態邊界任務的華麗翻牌與解鎖特效。  
  * `[M3.5.3] 技能樹與知識圖譜 (Skill Trees)` `[進階]`：將收藏品轉化為具備依賴關係的網狀點亮圖。  
* **\[M3.6\] 社群與社會情懷介面 (Community UI)**  
  * `[M3.6.1] 社交隔離與子社群切換 (Bento Grid)` `[進階]`：透過垂直輪盤切換「陌生人」、「朋友圈」與「讀書會」等不同社交壓力屬性區塊。  
  * `[M3.6.2] 社群共識與動態牆 (Consensus & Posts)` `[進階]`：靜態展示社群規範，動態展示同儕成就。  
  * `[M3.6.3] 承諾與驗證閉環 (Commitment Contracts)` `[進階]`：展示 Task \-\> Commitment \-\> Validation 流程，並實作「XP 質押對賭」的硬核操作 UI。

    ## **🧠 \[M4\] 混合式大腦與多智能體層 (FastAPI \+ LangGraph)**

*(系統業務邏輯核心)*

* **\[M4.1\] 狀態與生命週期管理**  
  * `[M4.1.1] 雙層 API 閘道器` `[MVP]`：處理本地端介面請求；`[進階]` 處理雲端跨裝置同步請求。  
  * `[M4.1.2] SQLite Checkpointer` `[MVP]`：LangGraph 對話樹狀態的持久化讀寫。  
* **\[M4.2\] 智能體路由與對話邏輯**  
  * `[M4.2.1] Echo Mode 動態路由 (Rule-based)` `[MVP]`：接收標籤，切換 Persona Agent 人設 Prompt。  
  * `[M4.2.2] 對話主題即時萃取與專案自動建置引擎 (Auto-Project Detection)` `[MVP]`：Observer Agent 背景監聽對話內容，若發現連續的探討焦點，自動於資料庫創建專案 (Project)，實現「免宣告即啟動」的體驗。  
  * `[M4.2.3] 專家配對引擎` `[進階]`：依據使用者的初次測驗或長期圖譜，自動組合最適合的專家陣容。  
  * `[M4.2.4] LLM-as-a-Judge 路由` `[進階]`：交由 Gemini 動態決定發言專家。  
* **\[M4.3\] 程序化內容生成引擎 (PCG)**  
  * `[M4.3.1] ZPD 盲盒生成排程 (Cron)` `[MVP]`：每日凌晨批次產出。  
  * `[M4.3.2] Leonardo.ai 素材串接` `[進階]`：以 API 動態生成卡牌資產並快取 URL (MVP 暫以 Pollinations 替代)。

## **🕸️ \[M5\] 深度認知與幻覺防禦層 (Deep Cognitive Pipeline)**

*(圖譜運算與邏輯驗證)*

* **\[M5.1\] 記憶提煉管線 (Graph Ingestion)**  
  * `[M5.1.1] 冰山映射提示詞工程` `[MVP]`：將流水帳翻譯為 Satir Model 的五層結構。  
  * `[M5.1.2] Cypher 轉譯與寫入器` `[MVP]`：呼叫 Neo4j AuraDB API 建立 Nodes & Edges。  
* **\[M5.2\] 神經符號幻覺防禦 (NSVIF)**  
  * `[M5.2.1] 外部證據驗證器 (Evidence Validator)` `[MVP]`：檢查圖譜連線是否有底層日誌支撐。  
  * `[M5.2.2] 本體論強制約束 (Ontology Enforcer)` `[MVP]`：阻擋不符合心理學邏輯的錯誤因果連線。  
* **\[M5.3\] 脈絡注入引擎 (Context Retrieval)**  
  * `[M5.3.1] Agent 說話前置查詢 (Pre-fetch)` `[MVP]`：在對話產生前，先撈取 Neo4j 子圖譜注入 Prompt 增強同理心。

## **🗄️ \[M6\] 混合儲存與同步層 (Database Abstractions)**

*(資料庫 ORM 與操作介面)*

* **\[M6.1\] 本地隱私金庫 (SQLite DAL)** `[MVP]`  
  * 實作 `raw_tracking_logs`, `chat_transcripts`, `edge_event_buffer` 的 CRUD。  
* **\[M6.2\] 雲端業務帳本 (PostgreSQL DAL)** `[進階]`  
  * 實作跨裝置的 `users`, `expert_projects`, `zpd_tasks` 等同步邏輯。  
* **\[M6.3\] 同步與衝突解決機制 (Sync Engine)** `[進階]`  
  * 處理離線狀態下的 XP 累積，並在連線後與雲端 PostgreSQL 進行合併 (Merge)。

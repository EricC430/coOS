# **Life OS 系統架構與技術選型總覽 (v1.1)**

**文件狀態**：已定案 (MVP 階段)

**架構哲學**：邊緣雲端協同 (PRISM) & 混合式本地優先 (Hybrid Local-First)

**核心目標**：在零硬體擴充成本、零初始 API 費用的前提下，打造具備極致隱私保護與薩提爾冰山深層心理認知分析的個人化多智能體作業系統。

## **壹、 四層式分散式運算架構 (Four-Tier Distributed Architecture)**

### **1\. 端側感知與介面層 (Ambient Tracking & UI)**

* **定位**：系統神經末梢，負責資料收集與前端展示。  
* **硬體載體**：筆電 (Intel i5, 16GB RAM)  
* **核心技術**：Tauri (Rust) \+ React/Vue  
* **架構決策**：  
  * **防抖與事件佇列 (Debounce & Batch Queue)**：攔截高頻率系統操作（如頻繁切檔案），每 30\~60 秒打包一次任務，避免塞爆後端推論伺服器。  
  * **隱私隔離庫**：使用 **本地 SQLite** 儲存最敏感的原始碼、日誌明文與對話逐字稿，資料絕對不上雲。

### **2\. 邊緣推論與隱私層 (Edge Inference & Semantic Compression)**

* **定位**：隱私過濾海關與意圖翻譯官。  
* **硬體載體**：iPad Air (M1, 8GB RAM) 區域網路伺服器  
* **核心技術**：ai.local (Ollama-style API)  
* **模型選型**：**Gemma-4-E4B-Instruct (4-bit 量化)**  
  * *原因*：40 億參數具備精準語意理解力，記憶體佔用小於 3GB，推論速度可達 6 秒內，且完全不干擾筆電主機效能。  
* **架構決策**：將原始行為降維壓縮為「去識別化意圖標籤」(如：鑽研、焦慮)，徹底阻斷原始碼外流風險。

### **3\. 混合式多智能體層 (Hybrid Agentic Layer)**

* **定位**：業務大腦與虛擬 Persona 專家群。  
* **硬體載體**：MVP 階段為 **本地筆電 (Tauri Sidecar)**；未來進階為 **本地 \+ 雲端 PaaS** 雙軌並行。  
* **核心技術**：Python (FastAPI) \+ LangGraph  
* **架構決策 (Local-First API)**：  
  * **\[本地大腦 (MVP 階段)\]**：FastAPI 作為本地背景行程 (localhost:8000) 隨 Tauri 啟動，直接讀取本地 SQLite。對話明文完全不出筆電，達成 0 毫秒極低延遲與極致隱私，且零伺服器託管成本。  
  * **\[雲端非同步大腦 (進階階段)\]**：將耗時的排程任務（如半夜結算每日報告、生成 ZPD 盲盒池）與手機端連線 API 部署至雲端 (Render, AWS)，實現跨裝置同步。  
* **核心模組實作路線決策**：  
  * **\[決策 A\] 短期記憶管理**：**路線 A1 (SQLite/PostgreSQL 共用)**。MVP 先以本地 SQLite 儲存 LangGraph 對話樹狀態，未來跨裝置需求出現時無縫轉移至雲端 PostgreSQL。  
  * **\[決策 B\] 路由觸發機制**：**路線 B1 (Rule-based)**。以 0 延遲的 Python 邏輯規則（如 if tag \== "焦慮"）觸發專家語氣切換。  
  * **\[決策 D\] ZPD 盲盒生成**：**路線 D2 (預生成池)**。由 FastAPI 排程批次計算難度適中的任務，實現 0 毫秒抽卡體驗。

### **4\. 深層認知與動態圖譜層 (Deep Cognitive & GraphRAG)**

* **定位**：系統的長期潛意識與幻覺防禦盾牌。  
* **核心技術**：Neo4j (圖資料庫) \+ Google AI Pro (Gemini 3.5 Pro API)  
* **核心模組實作路線決策**：  
  * **\[決策 C\] 心理幻覺防禦 (NSVIF)**：**路線 C2 (符號邏輯攔截)**。Gemini 推論出的薩提爾冰山洞察，必須經由 Python 腳本對照資料庫實體 ID 進行「反溯因驗證」，不合邏輯直接丟棄，根絕 AI 胡說八道。

## **參、 未來進階與擴展藍圖 (Future Upgrade Paths)**

當 MVP 跑通、數據量變大或需要更極致的效能時，系統架構已預留了以下平滑升級的空間：

1. **架構與資料庫層級升級**  
   * **本地高併發改造**：若未來本地紀錄頻率大幅提升，可將本地 SQLite 無縫升級為 **本地原生安裝版 PostgreSQL**（需手動調降 shared\_buffers 以適應 16GB RAM 的硬體極限）。  
   * **雲端跨裝置啟動**：當需要手機連線時，將特定 FastAPI 路由（如讀取盲盒、社群動態）部署至雲端 Render，啟動「前線本地 \+ 後勤雲端」的雙軌混合大腦。  
   * **圖譜容量解鎖**：若 Neo4j AuraDB 的 20 萬節點限制被突破，可轉為在自有的低成本 VPS 伺服器上自建 **Neo4j Community Edition**，解鎖數十億節點的無限圖譜。  
2. **智慧決策層級升級**  
   * **動態 LLM 路由 (B1** $\\rightarrow$ **B2)**：將原本寫死的 Python 路由切換規則，升級為 LLM-as-a-Judge，讓系統具備更細膩的語境同理心，動態調配最適合的專家出面應對。  
   * **Redis 記憶體快取 (A1** $\\rightarrow$ **A2)**：將 LangGraph 的短期對話狀態管理從關聯式資料庫抽離，改用 Redis 記憶體資料庫，實現超大型語言系統級別的極低延遲對話串流。  
3. **視覺生成層級升級**  
   * 從 Pollinations.AI 全面切換至 **Leonardo.ai API**，透過設定固定的模型風格 ID (Style Reference)，打造 100% 統一的 3D 遊戲化或賽博龐克風格介面資產。

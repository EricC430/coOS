## 衝突解決順序

當不同研究的建議相互衝突時,優先順序:

1. **隱私約束 (R07 + R06)** — 絕對最高優先,違反隱私一律拒絕實作
2. **安全性 (R02 DRIFT + R04 NSVIF)** — 防 Prompt Injection 與心理幻覺
3. **使用者心理所有權 (R08)** — 不可為了優化體驗就剝奪使用者裁量權
4. **人設一致性 (R03 ARPM)** — 長對話下絕對不能崩塌
5. **學習效率 (R01 ZPD)** — 在前 4 個約束內最大化
6. **產品功能完整性** — 最後考量

## 常見錯誤引用範例

❌ **錯誤** (混淆模組與研究):
```python
# M4.2 使用 Echo Mode
```

✅ **正確**:
```python
# [R03: Echo Mode §3.2] 實作 M4.2.2 的 Agency 切換
```

❌ **錯誤** (引用太籠統):
```python
# 根據 R08 設計草稿核准
```

✅ **正確**:
```python
# [R08: §四.2 微摩擦力] 強制 user_feeling 欄位非空,觸發 System 2
```

❌ **錯誤** (虛構引用):
```python
# 根據 R11 的最新研究...
```
(R11 不存在,目前只有 R01~R10)

✅ **正確** (誠實表達不確定):
```python
# 沒有對應研究,此設計來自產品架構文件 §2.5
# TODO: 待 Reviewer 拍板是否需要補學術依據
```

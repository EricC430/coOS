# coOS 視覺識別指南

**版本**:2.0(取代 v1 冰山/深度圖方向)　**日期**:2026-08-12

## 為什麼換方向

v1 用「薩提爾冰山」畫成冷色系測深圖(海軍藍+青綠)。概念上說得通,但跟實際上線的介面(見 `reports/ui_images/`)完全對不上——coOS 目前的 UI 是暖色系深棕底 + 金橘/赭橙強調色,character 頭像+ 深夜書桌燈光的陪伴氛圍,不是冷冽的航海圖表。色票衝突,識別系統形同虛設。

v2 直接從實際介面截圖取樣真實色票(見下),概念換成**羅盤**——這也是使用者原本嘗試過的「舵/領航」直覺,只是舊版執行方式(細輻條的舵輪)在小尺寸下會糊掉。v2 拿掉細節,改成粗指針 + 淺色錶盤,同時在概念上更精準:指北針不會自己動,它只是誠實反映「你自己」的方向——呼應 coOS「AI 不替你做決定,只負責校準」的核心哲學(強制核准機制保留心理所有權,見 CLAUDE.md 隱私與治理原則)。

## 色彩(取樣自真實介面,非憑空設計)

| Token | Hex | 來源 / 用途 |
| ---- | ---- | ---- |
| `espresso-dark` | `#0C0805` | 取樣自 `setting.png` 背景 —— 徽章底色深端 |
| `espresso` | `#271A12` | 徽章底色漸層淺端 |
| `card` | `#1C120B` | 錶盤外環、卡片底 |
| `dial` | `#F3E4CC` → `#E3C99E` | 錶盤面(高對比淺色,確保指針在任何尺寸都讀得出來) |
| `amber` | `#F2A73D` / `#D9722C` | 取樣自 `setting.png` 儲存按鈕 —— 主要強調色、指針北端 |
| `terracotta` | `#C2614A` | 取樣自 `mainpage.png` 長條圖 —— 次要強調色 |
| `gold` | `#EBC22D` 系 | 取樣自 `chat-with-expert.png` 使用者訊息泡泡 —— 最亮強調(少量使用) |

**教訓(務必記住)**:色相不同不等於對比足夠。v1 羅盤第一版用「深棕錶環 vs 深棕底」失敗,原因是兩者明度太接近,在暗色背景上直接消失。任何新增圖形元素,先檢查明度(灰階)對比,而不是只看色相是否好看。

## 備選方向:提燈 (Lantern)

過程中也做過「提燈」概念(暖光象徵「你自己提著燈走,AI 不替你走」),小尺寸辨識度略遜於羅盤但概念同樣成立,情感上更柔和/陪伴感更重。若之後想要更溫暖、較不強調「工具理性」的方向,可以回頭精緻化這個備案(草稿邏輯留在此次對話紀錄,尚未產出正式檔案)。

## 為什麼是這個方向(而不是常見的 AI 產品識別)

- **不用紫藍漸層 + 白底**:通用 AI 新創樣板,coOS 對這類視覺免疫的工程師/研究者受眾不會被打動。
- **不用 4 點 AI 閃光/sparkle 圖示**:那是 Gemini、Copilot 等一票 AI 產品的通用「這是 AI 產品」符號,做過測試(見對話紀錄的概念比較稿)確認辨識度雖然夠,但完全沒有差異化,已排除。
- **不迴避暖色系**:雖然「暖米色+襯線+陶土色」常被列為 AI 生成設計的樣板臉,但這裡是**先有真實產品色票、再對齊**,不是憑空選的預設值——差別在於這是深底(espresso,不是米白)+ 高對比錶盤,而不是淺底陶土色的樣板組合。
